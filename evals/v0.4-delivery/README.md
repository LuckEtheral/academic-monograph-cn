# 自拟交付层回归

本目录只验证只读工具和文件交付流程，不评测模型正确率。

inputs为独立编写样本，expected为预期，outputs/actual.json为实际执行输出；不包含私有书稿、真实报告、作者姓名或参考书扫描。

在环境有Python标准库时运行：

```sh
python evals/v0.4-delivery/run_regression.py
```

程序复制三个样本到临时目录，以独立工具进程检查正常、异常及正常代码/表格对照；另查缺失文件、目录与直接符号链接的读取失败。输入不改；异常是需上下文复核的提示，不自动修订。JSON/UTF-8往返保存theta、times、frac、beta、ne、偏导、上下标、函数括号、弱不等号和集合归属。

实际有限回归通过。只说明这些自拟输入的表现；不保证所有合法变量都无误报或所有转义错误都可发现，不证明所有渲染器兼容。没有建立CI、浏览器框架或付费API流程。
